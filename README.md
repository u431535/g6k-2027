台灣世界展望會 2027 Global 6K For Water 互動導覽頁（3D 取水之路）與**全新「🏃 線上跑步」虛擬路跑系統**。

- 報名截止：2026 年 12 月 31 日

## 🏃 線上跑步模式（Virtual Run Mode）

點擊右上角導覽列中的 **「🏃 線上跑步」** 按鈕，即可開啟參賽組別選擇並化身為 Global 6K 跑者進入 3D 賽道場景！

### 🎽 參賽組別選擇
進入跑步前，可自由選擇兩大官方活動組別：
1. **🏃 一般體驗組（報名費 NT$ 700）**：
   - 雙手放空，自然輕盈擺臂奔跑。
   - 體驗 6 公里孩童每日取水步行的日常距離。
2. **🪣 負重挑戰組（報名費 NT$ 850，推薦體驗）**：
   - 單手手持裝滿 20 公升飲用水的黃色水桶（Jerry Can，如官方宣傳圖所示）。
   - 專屬負重跑步姿態與擺臂動畫，深度共感孩童長途負重的艱辛。
   - 跑步途中亦可隨時點擊頂部 HUD 組別徽章自由切換！

---

### 📱 手機端操作體驗優化（雙手拇指人體工學佈局）
專為手機觸控螢幕打造極致操控體驗：
1. **雙手拇指人體工學按鍵**：
   - **左手拇指區域**：左下角設有大型 **`◀ 往左`** 與 **`往右 ▶`** 按鍵，大拇指輕鬆切換跑道。
   - **右手拇指區域**：右下角設有超大 **`👟 往前跑`** 脈衝按鍵，支援 **點擊踏步** 或 **按住持續奔跑**，手指不酸痛。
2. **全螢幕觸控滑動手勢**：
   - 左右滑動螢幕畫面任一處即可轉向。
   - 觸碰並按住螢幕中下區域即可持續前進衝刺。
3. **⚡ 自動巡航模式**：
   - 點擊頂部 **「⚡ 自動跑」**，即可放開雙手，享受賽道與沿途景觀。

---

### 💻 電腦端鍵盤操作
- **前進奔跑**：按下 **`W`**、**`↑`** 或 **`空白鍵 (Space)`**。
- **左右轉向**：按下 **`A`** 或 **`←`** 往左，**`D`** 或 **`→`** 往右。
- **退出跑步**：按下 **`Esc`** 鍵。

---

### 🏆 完賽慶祝與證書
- 跑至 6.0 KM 終點拱門時觸發衝線慶祝、歡呼音效與滿天彩色紙花。
- 自動生成完賽賀卡與成績記錄（包含參賽組別認證、耗時、平均時速及為孩子爭取水量）。

## 🚀 本地啟動方式

本專案無需任何外部編譯工具，已內建輕量 HTTP 伺服器：

```bash
# 方式 1: 使用 npm 啟動
npm start

# 方式 2: 直接使用 Node.js
node server.js

# 方式 3: 使用 Python (若無 Node.js)
python -m http.server 3000
```

開啟瀏覽器造訪：[http://localhost:3000](http://localhost:3000)
